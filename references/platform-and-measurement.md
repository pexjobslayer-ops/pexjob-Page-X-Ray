# Meta Platform & Measurement References

Use this as a **source map**, not a permanent snapshot of product behavior. Meta changes UI labels, available objectives/performance goals, attribution options, and policy interpretation. Open the relevant official page and confirm the exact choices in the user's Ads Manager before giving account-specific instructions. Do not infer that every listed option is available in every account or market.

## How to apply the sources

1. **Objective vs. performance goal:** determine the business outcome first, then verify both the available objective and the ad-set performance goal. Do not use a cheap proxy event as proof of sales.
2. **Attribution:** record the chosen model/setting and reporting window. Do not compare reported conversions directly across unlike settings; use compatible definitions or report the comparison limitation.
3. **Policy:** inspect the final wording, visual, offer, audience and destination. Avoid assertions or implications about an individual's personal attributes. A compliant-looking draft is not a guarantee of approval.
4. **Measurement:** state which system produced each number (Ads Manager, analytics, CRM, POS), how events map, the date window and timezone. Reconcile definitions before explaining gaps.
5. **Currency / budget / delivery:** read account-specific values directly from the current account context; never assume a universal minimum budget or invent expected costs.

## Source discipline

Treat documentation as current only after reopening it for the task. A search result is a pointer, not evidence for a detailed policy or product claim. If documentation or the account UI cannot be accessed, say so and keep recommendations conditional.
