- ต้องเลือก / แก้ / พิสูจน์อะไร:

## ธุรกิจและข้อเสนอ
- สินค้า/บริการ ราคา และเงื่อนไขข้อเสนอ:
- ลูกค้า/สถานการณ์ที่ซื้อจริง:
- หลักฐานความน่าเชื่อถือที่ใช้ได้:
- Gross margin หรือเพดานต้นทุนต่อผลลัพธ์ (ถ้ามี):
- ขั้นตอนปิดการขาย, close rate, refund/return (ถ้ามี):

## ช่องทางและประสบการณ์
- Facebook/Instagram Page, เว็บไซต์, ฟอร์ม, แชต หรือหน้าร้าน:
- เส้นทางตั้งแต่เห็นโฆษณาถึงซื้อ:
- เวลาตอบกลับ/ข้อจำกัดการส่งมอบ:
- ลิงก์/ภาพ/ข้อความ/Creative ที่ต้องการให้ตรวจ:

## ผลโฆษณาและการวัดผล
- ไฟล์หรือภาพ Ads Manager / CRM / Analytics:
- ช่วงวัน, เขตเวลา, สกุลเงิน และระดับข้อมูล (Campaign / Ad set / Ad):
- Objective, performance goal และ attribution setting (ถ้าทราบ):
- นิยาม Metric/Conversion และ event tracking ที่ใช้:
- การเปลี่ยนงบ/Creative/หน้าเว็บ/ราคาในช่วงรายงาน:

## ข้อจำกัด

- ข้อจำกัดด้านนโยบาย กฎหมาย ความเป็นส่วนตัว หรือแบรนด์:
